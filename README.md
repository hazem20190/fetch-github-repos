# Fetch GitHub Repos

A simple JavaScript application that fetches and displays public repositories from any GitHub user using the GitHub REST API.

## Live Demo

[View Live Demo](https://hazem20190.github.io/fetch-github-repos/)

## Features

- Fetch public repositories by GitHub username.
- Display repository names.
- Show the number of stars for each repository.
- Visit repositories directly on GitHub.
- Handle API errors using Fetch API.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- GitHub REST API

## How to Use

1. Open the application.
2. Enter a GitHub username.
3. Click the button to fetch repositories.
4. View repository names, star counts, and links.

## API

This project uses the GitHub REST API:

`https://api.github.com/users/{username}/repos`
